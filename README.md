# uptime-watch

ตัวเฝ้าระวังภายนอกสำหรับเซิร์ฟเวอร์ที่บ้าน (`https://hermes-linux.basa-ide.ts.net`)

- GitHub Actions วิ่งทุก 30 นาที ยิง HTTP ไปที่เว็บ 3 ครั้ง ถ้าไม่ตอบ 200 ถือว่าล่ม
- เมื่อล้มเหลว GitHub จะส่งอีเมลแจ้งเจ้าของ repo อัตโนมัติ
- ข้อดี: อยู่คนละที่กับเซิร์ฟเวอร์ จึงยังแจ้งเตือนได้แม้ไฟบ้านดับ/เน็ตหลุด
- ทดสอบด้วยมือ: Actions → uptime-check → Run workflow (ใส่ URL อะไรก็ได้เพื่อลองกรณีล่ม)

ระบบที่อยู่ในเครื่อง (watchdog ทุก 15 นาที + สรุปเช้า 08:00) ทำงานคู่กัน: ตัวในเครื่องจับปัญหารายละเอียด ส่วนตัวนี้จับกรณี "เครื่องหายไปทั้งเครื่อง"
